# 一箭又一箭 (Arrow by Arrow)

**GitHub仓库**: https://github.com/trony33/arrow-game

## 游戏简介

"一箭又一箭"是一款点击式箭头解谜游戏。玩家需要观察棋盘中箭头的方向和相互阻挡关系，按照合适的顺序点击箭头，使所有箭头依次飞出棋盘。

## 游戏规则

1. 棋盘中包含若干带方向的箭头（上、下、左、右四种方向）
2. 玩家点击某个箭头后，程序检查该箭头前进方向上的路径：
   - 如果箭头与棋盘边界之间没有其他箭头阻挡，该箭头飞出棋盘并被消除
   - 如果路径上存在其他箭头，该箭头不能被消除，并给出碰撞反馈
3. 点击被阻挡的箭头会消耗一次失误机会
4. 清除本关全部箭头后即可进入下一关
5. 失误次数耗尽时，本关失败，可重新开始

## 游戏特色

- **5个精心设计的关卡**：从简单到复杂，逐步增加难度
- **直观的图形界面**：清晰的箭头显示和流畅的动画效果
- **音效系统**：飞出、碰撞、通关、失败都有对应音效
- **提示系统**：卡关时可获得提示帮助
- **失误追踪**：显示剩余失误次数，增加游戏挑战性

## 开发环境

- Python 3.8+
- Pygame 2.5.0+

## 安装和运行方法

1. 安装依赖：
```bash
pip install -r requirements.txt
```

2. 运行游戏：
```bash
python main.py
```

或者使用运行脚本：
```bash
python run_game.py
```

## 游戏操作说明

- **鼠标左键**：点击箭头尝试消除
- **R键**：重新开始当前关卡
- **H键**：显示提示（闪烁显示可点击的箭头）
- **M键**：静音/开启音效
- **ESC键**：返回主菜单/退出游戏

## 游戏界面

### 主菜单
- 显示游戏标题和基本规则
- 开始游戏按钮

### 游戏界面
- 顶部：关卡名称、剩余箭头数量、失误次数
- 中部：游戏棋盘，显示所有箭头
- 右侧：操作按钮（重新开始、提示、静音）

### 结算界面
- 通关：显示通关信息，可进入下一关
- 失败：显示失败信息，可重新开始
- 全部通关：显示祝贺信息
